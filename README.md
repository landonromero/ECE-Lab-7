## Summary
In this lab we used a truth table to create a half subtractor. We then used full adders to make a ones compliment adder which takes a number and adds it to another number and has a wrap around feature that lets you add negative numbers. This module has two stages first the addition of the 2 numbers then the addition of the sum and a 0 bit with the carry around from the first stage. The last thing we did was make a twos compliment module. In that module we invert the 8 bit input number and we add 1 to each bit with a carry. That gives us the inverted number.
